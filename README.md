# VITA FORM — Wellness Supplement Store

An English-language, responsive storefront template built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the project ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.

## Customize before publishing
- **Brand:** replace `VITA FORM` in `index.html`.
- **Products:** edit the product cards in the `#products` section. Use only accurate names, ingredient lists, directions, warnings, images and prices.
- **Contact:** update `storeEmail` in `script.js`.
- **Currency:** prices are sample USD amounts. Change them to your market's currency and actual prices.
- **Images:** replace the Unsplash image URLs with licensed product photography.
- **Colors and layout:** edit `style.css`.

## Included
- Responsive layout and mobile navigation.
- Product category filters.
- Demonstration cart with item count and total.
- FAQ section and contact link.
- English copy throughout.

## Important limitations and compliance
The cart is a front-end demonstration only. It does not process payments, collect orders, manage inventory or store customer data. Connect a secure checkout and backend before accepting orders.

All product names, images, descriptions and prices are placeholders. This template intentionally avoids weight-loss promises or medical claims. Before selling dietary supplements, verify product authorization, labeling, ingredients, warnings, advertising and sales requirements in every target market. Never publish unsubstantiated claims or imply that a supplement treats, cures or prevents disease. Have all product and advertising copy reviewed by qualified regulatory and healthcare professionals.
